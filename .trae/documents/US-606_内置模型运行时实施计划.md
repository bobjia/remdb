pub enum ModelRequest {
    LoadModel { name: String, path: String },
    Execute { model: String, inputs: Vec<Vec<f32>> },
    UnloadModel { name: String },
    ListModels,
    Shutdown,
}

pub enum ModelResponse {
    Success,
    ModelLoaded { metadata: ModelMetadata },

    Error { message: String },

## 风险与缓解

| 风险                 | 影响 | 缓解措施                |
| ------------------ | -- | ------------------- |
| ONNX Runtime跨平台兼容性 | 高  | 使用预编译库，提供fallback方案 |
| 模型文件体积过大           | 中  | 使用量化模型，支持按需下载       |
| 进程间通信延迟            | 中  | 使用共享内存优化，批处理请求      |
| 内存占用过高             | 高  | 严格内存限制，模型卸载机制       |
