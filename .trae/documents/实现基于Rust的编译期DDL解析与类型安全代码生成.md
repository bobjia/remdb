# 实现US-209和US-210：基于Rust的编译期DDL解析与类型安全代码生成

## 1. 需求分析

### US-209：基于Rust的编译期DDL解析与类型安全代码生成
- 解析SQLite3语法兼容的DDL文件
- 编译期语法和语义检查
- 生成强类型Rust结构体和元数据
- 生成类型安全的API原型
- 零运行时开销，使用过程宏实现

### US-210：基于Rust过程宏的零成本DDL集成
- 提供`MemdbTable`过程宏，支持`#[derive(MemdbTable)]`和`#[memdb_schema]`属性
- 支持内联模式和文件模式
- 生成Rust实体结构体和表操作API
- 将SQL约束映射为Rust类型系统约束
- 零运行时解析，内存布局等同手写代码

## 2. 实现计划

- 生成强类型结构体：将SQL类型映射为Rust类型

## 4. 技术实现细节

### 4.1 DDL解析
- 使用递归下降解析法实现DDL解析
- 支持SQLite3核心DDL语法
- 实现详细的错误信息，包含行号和列号

### 4.2 类型映射
- `INTEGER` -> `i64`
- `TEXT` -> `String`或`&str`（根据上下文）
- `REAL` -> `f64`
- `BOOLEAN` -> `bool`
- `NOT NULL` -> 非`Option`类型
- 可为空列 -> `Option<T>`类型

### 4.3 代码生成
- 使用`syn`和`quote`库生成Rust代码
- 确保生成的代码`#[repr(C)]`，内存布局与手写代码一致
- 生成唯一的`TableId`类型，用于编译期区分不同表
- 生成静态元数据，供数据库引擎使用
