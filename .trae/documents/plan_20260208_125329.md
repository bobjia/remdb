# 实现 JSON 函数

## 目标
在 SQL 查询执行器中实现 sql_language.md 中定义的所有 JSON 函数。

## 实现步骤

### 1. 在 `execute_function_call()` 中添加 JSON 函数分支
在 `remdb/src/sql/query_executor.rs` 的 `execute_function_call()` 函数中添加 JSON 函数的匹配分支。

### 2. 实现各个 JSON 函数的执行函数

#### 提取函数：
- `execute_json_extract()` - 调用 `json::document::json_extract()`
- `execute_json_value()` - 提取标量值
- `execute_json_query()` - 提取对象或数组
- `execute_json_has()` - 调用 `json::document::json_has()`，返回布尔值
- `execute_json_type()` - 调用 `json::document::json_type()`，返回类型字符串

#### 修改函数：
- `execute_json_set()` - 调用 `json::document::json_set()`
- `execute_json_remove()` - 调用 `json::document::json_remove()`
- `execute_json_merge_patch()` - 调用 `json::document::json_merge_patch()`
- `execute_json_array_append()` - 向数组追加元素

#### 构造函数：
- `execute_json_array_length()` - 计算数组长度
- `execute_json_array()` - 创建JSON数组
- `execute_json_object()` - 创建JSON对象

### 3. 处理 JSON 类型的参数和返回值
- 从 `TypedValue` 中提取 JSON 字段值（`JsonStorage` 类型）
- 将 JSON 字符串转换为 `JsonDocument`
- 将执行结果转换回 `TypedValue`

### 4. 运行测试验证
运行 `remdb/tests/json_functions_test.rs` 中的测试用例，确保所有函数正常工作。

## 涉及的文件
- `remdb/src/sql/query_executor.rs` - 主要修改文件
- 可能需要查看 `remdb/src/json/document.rs` 中的现有实现作为参考
