# 支持DESCRIBE TABLE指令实现计划

## 目标

实现DESCRIBE TABLE指令，用于查看表的字段和索引信息。

## 实现步骤

### 1. 扩展查询类型

* 在`query_parser.rs`的`QueryType`枚举中添加`Describe`变体

* 修改`parse_query_type`方法，识别`DESCRIBE`关键字

### 2. 修改查询解析器

* 修改`SqlQuery`结构体，支持DESCRIBE查询

* 添加`parse_describe_query`方法，解析DESCRIBE TABLE查询

* 修改`parse`方法，处理Describe查询类型

### 3. 修改查询执行器

* 修改`execute_query`函数，添加对Describe查询类型的处理

* 添加`execute_describe_query`函数，执行DESCRIBE TABLE查询

### 4. 实现DESCRIBE查询逻辑

* 获取表的字段信息：字段名、数据类型、大小、是否为主键等

* 获取表的索引信息：索引类型、索引字段等

* 构建包含字段和索引信息的结果集

### 5. 测试

* 添加DESCRIBE TABLE指令的测试用例

* 确保现有的SQL查询功能仍然正常工作

## 预期效果

用户可以使用如下方式查看表的字段和索引信息：

```rust
let result = db.sql_query("DESCRIBE TABLE users")?;
println!("{}", result.to_string());
```

## 技术要点

* 保持与现有代码的兼容性

* 提供清晰的表结构信息

* 支持多种输出格式

* 确保查询执行的高效性

## 注意事项

* 只支持DESCRIBE TABLE语法，不支持DESC TABLE的简写

* 输出结果应包含字段名、数据类型、大小、是否为主键等信息

* 输出结果应包含索引信息，包括索引类型和索引字段

* 保持与SQL标准的兼容性
